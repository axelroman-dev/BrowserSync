Restore bookmarks from server

Replaces this device's bookmarks with whatever's currently synced on the server. Use this if this device's bookmarks ever end up wrong or out of sync.

Push this device's bookmarks to the server

The reverse of restoring: discards whatever's currently synced and replaces it with this device's bookmarks instead. Use this if the server ended up with the wrong bookmarks and this device has the ones you actually want.

Delete account and all synced data

This permanently deletes your account and every synced blob from the server. It cannot be undone.
